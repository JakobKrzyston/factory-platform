# skills

Shared by every agent in this factory, one folder per skill holding a `SKILL.md`. `pr-description/` is appended by `scripts/run-issue.sh` to the prompt of every `pull-request` agent, here implement, because that contract's gate checks the description it describes. A skill added here is not loaded until a contract names it. Skills for one agent only live under that agent's folder, such as `agents/review/skills/cite-standards/`.
